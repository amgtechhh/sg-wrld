# SG wrld — Aesthetic Life (60 / 30 / 10 Brand Edition)

Next.js 14 (App Router), TypeScript, Tailwind CSS, and Lucide Icons.

## Brand Palette
- **60% Dominant Surface:** `#d7ddd2` (Architectural Paper)
- **30% Secondary Structural:** `#4b1827` (Deep Plan Burgundy)
- **10% Primary Accent:** `#ff6b1a` (High-Vis Amber Orange)

## Getting Started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```
